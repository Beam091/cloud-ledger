# Ledgerly Version History

## v1.0.5
- วันที่: 2026-10-18
- ปรับปรุง: เข้ารหัส Telegram bot token และ Discord webhook ที่เก็บในฐานข้อมูล
- รายละเอียด:
  - ค่าที่บันทึกใหม่ถูกเข้ารหัส AES-256-GCM ก่อนเก็บใน D1 เช่นเดียวกับ App Password ของ Gmail
  - ค่าเก่าที่เป็น plain text ยังใช้งานได้ และจะถูกเข้ารหัสใหม่เมื่อผู้ใช้บันทึกหน้าการแจ้งเตือนครั้งถัดไป
  - เคลียร์ token ได้โดยลบค่าช่องกรอกแล้วบันทึก
- ผลกระทบ: ข้อมูลการแจ้งเตือนของผู้ใช้ไม่ถูกเก็บเป็นข้อความลอยอีกต่อไป

## v1.0.4
- วันที่: 2026-10-18
- ปรับปรุง: แก้บั๊กช่องว่างเวลา, ช่วงเวลาภาพรวม และการบันทึกการแจ้งเตือน
- รายละเอียด:
  - แก้ตัวกรองภาพรวมรายวัน/รายสัปดาห์ ที่ backend ไม่รับค่า period จึงแสดงยอดเดือนเสมอ
  - ใช้เขตเวลาของผู้ใช้ในการคำนวณยอดภาพรวมและสรุปแจ้งเตือน แทนการ fix ที่ UTC+7
  - แก้การบันทึกการแจ้งเตือนที่ลบ Telegram chat id ที่บันทึกไว้ทิ้งโดยไม่ตั้งใจ
  - ห้ามแก้ประเภทธุรกรรมเป็น transfer ผ่าน PATCH เพราะระบบยังไม่รองรับโอนระหว่างบัญชีจริง
- ผลกระทบ: ยอดภาพรวมตามช่วงเวลาและเขตเวลาถูกต้อง ข้อมูลการแจ้งเตือนไม่หาย

## v1.0.3
- วันที่: 2026-10-18
- ปรับปรุง: เลือกช่วงเวลาภาพรวมและยืนยันรายการจากภาพก่อนบันทึก
- รายละเอียด:
  - เพิ่มตัวเลือกภาพรวมรายวัน รายสัปดาห์ และรายเดือน พร้อมปรับยอดรวม หมวดหมู่ และกราฟตามช่วงเวลา
  - ปรับ AI ให้อ่านรายชื่อบัญชีที่มีอยู่ และจับคำบอกประเภทบัญชี เช่น e-Wallet หรือเงินสดจากข้อความ
  - เปลี่ยนการอ่านภาพเป็นหน้าตรวจสอบข้อมูลก่อนบันทึก ผู้ใช้แก้ยอด บัญชี และประเภทได้ก่อนยืนยัน
- ผลกระทบ: AI จะไม่สร้างรายการหรือปรับยอดบัญชีจากภาพจนกว่าผู้ใช้จะยืนยัน

## v1.0.2
- วันที่: 2026-10-17
- ปรับปรุง: ระบบเลือกบัญชีอัตโนมัติเมื่อ AI วิเคราะห์รายการ
- รายละเอียด:
  - เพิ่มการ normalize ชื่อบัญชีเพื่อให้เปรียบเทียบแบบยืดหยุ่น
  - รองรับ alias ชื่อธนาคารและบัญชียอดนิยม เช่น กรุงไทย, KTB, Krungthai, กสิกรไทย, ไทยพาณิชย์
  - ปรับให้เลือกบัญชีที่ตรงที่สุดแทนการเลือกบัญชีแรกแบบสุ่ม
  - ใช้ฟังก์ชันเดียวกันทั้งกรณี AI วิเคราะห์ข้อความและ AI อ่านสลิป/ใบเสร็จ
- ผลกระทบ: เมื่อลงรายการจากข้อความ เช่น "200 กรุงไทย" ระบบจะเลือกบัญชี "กรุงไทย" ได้ถูกต้องมากขึ้น

## v1.0.1
- วันที่: 2026-10-17
- ปรับปรุง: ปรับ UX สำหรับมือถือและการจัดการออกจากระบบ
- รายละเอียด:
  - เพิ่มปุ่ม logout สำหรับมือถือ
  - ปรับหน้าแจ้งเตือนให้เลือก cron เป็น daily / weekly / monthly
  - ส่งอีเมลแจ้งเตือนไปที่อีเมลของผู้ใช้โดยอัตโนมัติ
  - ปรับเรื่องสิทธิ์ admin และความปลอดภัยด้านการปิดบัญชีตัวเอง
