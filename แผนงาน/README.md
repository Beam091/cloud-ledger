# แผนงานและการดำเนินงานล่าสุด (v1.0.13)

**วันที่ดำเนินการ**: 1 พฤศจิกายน 2026  
**เวอร์ชันปัจจุบัน**: `v1.0.13`

---

## 1. วัตถุประสงค์ของการปรับปรุงครั้งนี้
1. **ยกเลิก Rate Limit ของ AI สำหรับบัญชีแอดมิน**: แอดมิน (`role === 'admin'`) สามารถใช้งาน AI ได้แบบไม่จำกัดโควตา (ไม่ติดเพดาน 30 ครั้ง/ชั่วโมง)
2. **แก้ไขยอดเงินคงเหลือในบัญชีได้โดยตรงและง่ายขึ้น**:
   - สามารถแก้ไขยอดเงินคงเหลือ (`balance`) ของบัญชีที่มีอยู่เดิมได้ทันทีผ่านหน้าต่างแก้ไขบัญชี
   - สามารถคลิกที่การ์ด/แถวบัญชีในหน้าภาพรวม (Overview) เพื่อเปิดแก้ไขยอดเงินและข้อมูลบัญชีได้สะดวกรวดเร็ว

---

## 2. รายละเอียดการแก้ไขในแต่ละส่วน

### 2.1 Backend / Cloudflare Worker (`worker/`)
- **`worker/src/index.ts`**:
  - อัปเดตการตรวจ Rate Limit ที่ `/api/ai/*`: เพิ่มเงื่อนไข `if (user.role !== 'admin')` ทำให้ผู้ใช้ที่มีสิทธิ์แอดมินไม่ต้องผ่านการจำกัดโควตา AI
  - อัปเดต `PATCH /api/accounts/:id`: เพิ่มการรองรับฟิลด์ `balance` พร้อมตรวจสอบความถูกต้องของจำนวนเงิน (`isValidAmount` / `MAX_AMOUNT_BAHT`) และแปลงเป็นหน่วยสตางค์ (`toSatang`) เพื่อบันทึกลงฐานข้อมูลอย่างแม่นยำ
- **`worker/tests/integration.test.ts`**:
  - เพิ่มชุดทดสอบ Integration Test ครอบคลุม:
    - การบายพาส Rate limit ของ AI เมื่อเป็น Admin เทียบกับ User ทั่วไปที่ยังคงติดลิมิต (HTTP 429)
    - การส่งคำขอ `PATCH /api/accounts/:id` เพื่อแก้ไขยอดเงินในบัญชีโดยตรง และตรวจสอบความถูกต้องของยอดเงินที่อัปเดต
